## 🚀 Featured Flagship Projects

### 1. 🎯 [HireScope ATS — Enterprise AI Candidate Screener](https://github.com/ganesh-badar/ai-resume-screener-ats)
> **Stack:** Java 17, Spring Boot 3.3, React 18, Server-Sent Events (SSE), OpenAI GPT-4o-mini, Apache PDFBox, MySQL
- **Problem Solved:** Traditional synchronous resume parsing blocks Tomcat servlet threads for 2–8s per upload, causing thread starvation under load.
- **Architecture:** Engineered the **Asynchronous Request-Reply Pattern (HTTP 202 Accepted)** using `@Async` worker thread pools (`ThreadPoolTaskExecutor`) and real-time streaming via **Server-Sent Events (SSE)**.
- **Repository:** [github.com/ganesh-badar/ai-resume-screener-ats](https://github.com/ganesh-badar/ai-resume-screener-ats) &bull; **Live Demo:** [Demo Link](https://ganesh-badar.github.io/ai-resume-screener-ats/)
